# 실험

## 실험 1: 고정 보스 vs 적응형 보스

질문: 플레이어봇 집단이 진화할 때, 적응형 보스는 공략 고착을 늦추는가?

| | A: 고정 보스 | B: 적응형 보스 |
|---|---|---|
| 패턴 선택 | 거리에 따른 고정 확률 | 밴딧: 이 플레이어에게 잘 먹힌 패턴의 확률을 올림 |
| 플레이어 관찰 | 없음 | 구르기 방향과 타이밍, 선호 거리, 회복 시점 |
| 변형 사용 | 없음 | 관찰한 습관에 맞는 변형 |
| 예산 | | 적응 강도 상한 |

진행:

1. 유틸리티 Brain 플레이어봇 50개, 세대마다 각자 보스와 20판
2. 상위 20%는 남기고 나머지는 교차와 돌연변이로 교체, 100세대
3. 보스 A, B 각각 따로 진행, 사람 한계는 "일반 유저"와 "고인물" 두 가지

플레이어봇 유전자(초안):

- 공격 적극성, 강공격 대 평타 비율
- 선호 거리
- 구르기 방향 성향(좌, 우, 뒤, 보스 쪽 통과), 구르기 타이밍(빨리 대 끝까지 기다림)
- 회복약 쓰는 HP 기준, 남겨 둘 최소 스태미나

| 측정 | 질문 |
|---|---|
| 승률 80% 도달 세대 | 얼마나 빨리 공략되나 |
| 승률 그래프 모양 | 고이나, 계속 흔들리나 |
| 상위 봇 유전자의 다양성 | 정답이 하나인가, 여러 개인가 |
| 이긴 판 리플레이 | 어떤 공략법이 나왔나 |
| 시간 초과 비율 | 꼼수(카이팅)가 나오나 |

## 실험 2: 기법 대항전

FSM 단독, BT 단독, GOAP 단독, HTN 단독, 유틸리티 단독, 조합형을 같은 규칙으로 겨루게 해서 Elo 리그를 만든다. 각 기법은 자기 진화 대상으로 먼저 최적화한 뒤 겨룬다.

## 실험 3: 조합형 적응 보스 vs 진화한 고인물 봇

실험 1, 2에서 가장 강한 플레이어봇 집단을 상대로 조합형 적응 보스를 시험한다.
