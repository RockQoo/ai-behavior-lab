# 로드맵

단계마다 끝나면 Codex 리뷰를 받고, 동의한 지적을 고친 뒤 다음 단계로 간다.

## 1단계: 시뮬레이션 코어 (완료)

목표: 화면 없이 보스와 플레이어가 규칙대로 싸우고, 같은 시드면 같은 결과가 나온다.

- [x] 결정적 난수(`DeterministicRandom`), 고정 틱(초당 30틱)
- [x] 전투 규칙 v0 데이터(`CombatRules`, `DefaultRules`): [combat-rules.md](combat-rules.md)의 숫자
- [x] 공격 범위 판정(원, 부채꼴, 직선, 고리)
- [x] 행동 상태 머신: 선딜 → 판정 → 후딜, 여러 단계(2연타, 짧은 돌진 → 휩쓸기), 이동형 판정(구르기, 돌진)
- [x] 구르기 무적, 스태미나, 회복약, 경기장 경계, 몸 겹침 밀어내기
- [x] 사람 한계: 반응 지연, 위치 판단 오차, 조작 실수(`HumanLimits`)
- [x] `IBrain` 인터페이스(관찰 → 의도)와 기준선 Brain(단순 추격·공격)
- [x] 승패: HP 0, 180초 초과 시 보스 승
- [x] 콘솔 러너: 여러 판 병렬 실행, 승률·평균 시간·처리 속도, 결정성 확인
- [x] 단위 테스트

## 2단계: 관전 화면 + FSM Brain (완료)

관전 화면을 먼저 만들고, FSM은 화면으로 보면서 만든다.

- [x] 리플레이: 매 틱 상태 기록 + 상태 해시(`Replay/`), 러너 `replay`·`verify` 명령
- [x] Godot 4 C# 관전 화면: 도형, 머리 위 HP·행동, 노란색 예고·빨간색 판정, 무적 테두리, 상태 패널, 최근 사건,
      0.1~4배속·일시정지·한 틱씩·타임라인, 시드 입력, 파일 열기, 검증(이 런타임에서 다시 돌려 해시 비교)
- [x] `StateMachine<TState>`(열거형 상태, `IState`, `Transition`, 어느 상태에서든 전이 = 인터럽트)
- [x] FSM 보스(접근 → 공격(고정 순환) → 휴식, 오래 쫓으면 돌진, 난수 없음)
- [x] FSM 플레이어(접근·대기·반격·회피·회복·숨 고르기, 문턱값은 `FsmPlayerParameters`)
- [x] 판단 근거 패널: `IExplainableBrain` → `DecisionTrace`(상태, 전이 이유, 판단 값) → 리플레이 프레임(형식 버전 2)
- [x] 러너·화면에서 Brain 고르기(`--player`, `--boss`: baseline | fsm)

2단계 결과(2,000판, 일반 유저 한계, 밸런스 조정 후): 기준선 vs 기준선 12.9%, FSM vs 기준선 67.5%, 기준선 vs FSM 보스 15.3%, **FSM vs FSM 91.3%**.
조정 전(v0 처음 수치)에는 FSM 플레이어가 FSM 보스를 피격 0회로 파훼하고도 피해가 모자라 100% 시간 초과였다. 자세한 내용은 [combat-rules.md](combat-rules.md) "밸런스 기록".

## 3단계: 유틸리티 Brain + 진화 → 실험 1-A

- 유틸리티 Brain(점수 곡선 가중치 = 유전자)
- 진화 엔진(선택, 교차, 돌연변이), 세대별 통계, Elo
- 고정 보스를 상대로 플레이어봇이 고이는 과정 기록

## 4단계: 적응형 보스 → 실험 1-B

- 플레이어 습관 관찰(구르기 방향·타이밍, 선호 거리, 회복 시점)
- 밴딧 패턴 선택, 변형 패턴(지연, 2연타, 짧은 돌진, 고리) 사용, 적응 예산
- 고정 보스와 비교

## 5단계: BT, GOAP, HTN → 실험 2

- 세 Brain을 하나씩 추가, 기법별 진화 대상 정의
- 기법 대항전 Elo 리그

## 6단계: 조합형 → 실험 3

- 층별 조합(HTN 전략 + 유틸리티 선택 + BT 실행 등)
- 조합형 적응 보스 vs 진화한 고인물 봇

## 7단계: 사람이 직접 플레이

- Godot 입력, 사람 대 적응형 보스
- 필요하면 그림·소리(ChatGPT 이미지, Kenney)
